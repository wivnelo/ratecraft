# RateCraft 报价器

面向自由职业者、独立开发者、小型工作室和咨询顾问的中文项目报价计算器。把工时、硬成本、修改轮次、风险、利润率和税费放在一处，生成报价参考与可复制的客户沟通文案。

## 功能

- 输入项目类型、客户名称、目标时薪、预计工时和交付清单。
- 拆分人工成本、外采成本、修改缓冲、风险缓冲与加急费用。
- 调整目标利润率、折扣和税费比例。
- 展示固定报价、建议区间、启动预付款、折算时薪与预估利润。
- 一键复制中文报价文案。
- 在浏览器 `localStorage` 中保存当前表单。
- 提供中文页面元数据与社交分享图。

## 本地运行

需要 **Node.js >= 22.13.0** 和 npm。

```bash
git clone https://github.com/wivnelo/ratecraft.git
cd ratecraft
npm ci
npm run dev
```

打开终端显示的本地地址。项目通过 `vinext` / Vite 启动，不要直接把它当作默认配置的 Next.js 项目运行。

## 怎么使用

1. 填写项目与客户信息、预计工时和时薪。
2. 加入外采费用，设置修改轮次、风险和利润率。
3. 按实际情况设置加急、折扣与税费。
4. 检查结果拆分，调整交付范围。
5. 编辑交付清单，复制报价文案并自行审核后发给客户。

复制使用浏览器 Clipboard API，需要安全上下文（通常为 HTTPS 或 localhost）及浏览器允许访问剪贴板。

## 计算规则

设人工成本为「时薪 × 工时」：

| 项目 | 当前规则 |
| --- | --- |
| 修改缓冲 | 人工成本 × 修改轮次 × 2.5% |
| 风险缓冲 | 人工成本 × 风险比例 |
| 加急费用 | 开启加急时，人工成本 × 20% |
| 成本合计 | 人工 + 硬成本 + 修改缓冲 + 风险缓冲 + 加急费用 |
| 折扣前报价 | 成本合计 ÷（1 − 目标利润率），计算时利润率限制为 1%～75% |
| 税前报价 | 折扣前报价 ×（1 − 折扣比例） |
| 固定报价 | 税前报价 ×（1 + 税费比例） |
| 建议区间 | 固定报价的 90%～120% |
| 启动预付款 | 固定报价的 50% |
| 折算时薪 | 税前报价 ÷ max(1, 工时) |
| 预估利润 | 税前报价 − 成本合计 |

金额以人民币展示并取整。目标利润率用于按销售额计算利润，不是简单给成本加同等比例。上述比例是当前产品的计算约定，实际报价需要结合项目范围自行判断。

## 数据与功能边界

报价页面在浏览器中计算，当前页面代码没有提交报价到服务端的逻辑。表单保存在当前浏览器、当前站点的 `localStorage` 中，不会自动跨设备同步；清除站点数据会移除保存内容。

页面提到的「报价模板包」和「客户工作台」是商业化方向展示，当前仓库未实现购买流程、客户管理或品牌报价单导出。

## 开发与检查

```bash
npm run build
npm run start
npm test
npm run lint
```

- `npm test` 先构建，再执行 `tests/rendered-html.test.mjs`。
- 技术栈：React、TypeScript、Next.js API 兼容的 vinext / Vite、Cloudflare Vite 插件。
- 报价界面与计算逻辑：[`app/page.tsx`](app/page.tsx)。
- 样式：[`app/globals.css`](app/globals.css)。
- 运行配置：[`vite.config.ts`](vite.config.ts)。

修改分享图文案后，可运行：

```bash
node scripts/generate-og.mjs
```

该脚本依赖 `sharp`，但当前 `package.json` 未声明它；因此仅安装仓库依赖后不能保证运行成功。执行前需另行准备该依赖，常规启动不需要运行此脚本。
